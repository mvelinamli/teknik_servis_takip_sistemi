# Technical Service Tracking System

A robust, Java-based desktop application designed to streamline hardware maintenance workflows. It provides a clean, user-friendly interface to manage customers, track device repair statuses, and keep historical service records.

## Features

* **Interactive Dashboard:** View real-time statistics including total customers, registered devices, pending service queues, and completed repairs.
* **Customer & Device Management:** Easily register new customers, bind devices to their profiles, and view detailed customer lists.
* **Service Tracking:** Create new service tickets for hardware interventions and track them through the repair pipeline.
* **Service Archive:** Maintain a permanent history of all completed technical services for future reference.

## Tech Stack

* **Language:** Java (Object-Oriented Programming)
* **GUI Framework:** JavaFX
* **Styling:** CSS
* **Data Storage:** File I/O (Local `.txt` databases for persistence)
